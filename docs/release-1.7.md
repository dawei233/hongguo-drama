## 稳定性
保留官网身份选择、有限重试与备用源。新增公网地址、直连DNS与重定向防护；用户配置的代理保留使用，代理端DNS属于代理信任边界。

坏JSON或资料读取失败后保留原文件并暂停写入；单实例启动避免互相覆盖。下载校验视频轨、实际尺寸、有效时长，传输失败不能冒充完成；已存在的异常文件不自动覆盖。合并占用文件不能被任务删除，重复记录取最新分集。完整缓存可复用但仍核实来源与所选清晰度。

下载回包不再改变已经切走的播放目标；同集从在线换到本地保留暂停和进度；进入推荐再回剧库按最新进度继续。

## 摇一摇
热播推荐的分类栏进入“摇一摇”，点击短剧签筒随机取一部真实剧目。默认包含三个内置来源及已启用自定义来源；可限定单一来源。保留四个热播榜，不把其它目录冒充热播榜。候选来自当前返回的目录页，不代表全站抽样；某个来源失败时保留其余来源并提示。

## 自定义播放源（Issue #10）
在设置的“自定义播放源”填写名称与苹果 CMS V10 JSON API，先测试连接再保存。常见路径为 `/api.php/provide/vod/`。测试成功只说明目录接口可用，不保证所有分集有效。接口格式参考[苹果 CMS 文档](https://www.maccms.plus/api/collect.html)。

支持目录/分类/分页、搜索、详情、选集和明确以 `.mp4` 或 `.m3u8` 结尾的公网媒体URL。多播放线路按同集归并。收费或密码标识保留限制；不执行远程代码，不接XML、网页解析器或其他专有API。接口和媒体必须为合法HTTP(S)公网地址。没有内置未验证的自定义站点。

HLS仅支持有结束标记的点播，以及普通或AES-128分片。先准备完整分片至临时目录，用随应用提供的媒体工具生成MP4，再进入播放/下载；大型节目首次准备时间取决于网络与文件大小。分片/密钥/跳转逐项核验，取消或清理会释放临时内容。无需另装播放器。

停用、修改或删除源会停止该源在线准备和下载，保留已下载文件；再次启用可重试任务。自定义源与内置来源沿用应用代理设置；直连检查实际DNS，代理的最终解析由该代理负责。

## 验证边界
